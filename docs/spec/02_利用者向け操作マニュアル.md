# 02 利用者向け操作マニュアル

対象：人事・総務などで有給管理を行う担当者。専門知識は不要です。
画面の左メニュー「**有給管理**」から操作します。ご自身のアカウントに必要な権限がない項目は表示されない／開けないことがあります（権限の違いは本資料末尾「権限の目安」を参照）。

---

## 0. 運用開始前の準備（初回のみ）

1. 社員情報管理システム（employee-manager）が有効で、社員に**入社日**と**週勤務日数**が登録されていることを確認する。
2. **有給管理 → 有給ルール設定** を開き、
   - 付与日数の表が自社ルールと合っているか確認する（初期値は労働基準法の標準）
   - 「**内閣府CSVから祝日を取得・更新**」を押して祝日データを取り込む
   - 変更したら「**ルールを保存する**」を押す
3. 過去の付与・消化履歴がある場合は「有給インポート」で取り込む（→ 第6章）。

---

## 1. 従業員一覧（全社員の状況を見る）

**場所：有給管理 → 従業員一覧**

| 列 | 意味 |
|---|---|
| 社員コード／氏名／入社日／雇用区分／週勤務日数 | 社員情報（employee-manager の登録内容） |
| 残有給日数 | 今使える有給の合計日数（失効分は含まない） |
| 今年の消化 | 「今年」の消化日数。「今年」は**直近の付与日から1年間**（暦年ではない。03 参照） |
| 失効予告 | **3か月以内**に失効する有給が残っていれば「◯日が失効間近」と赤字表示 |
| 有給申請 | 未処理（申請中）の有給希望があると赤い件数バッジ。クリックで個人管理画面へ |
| 操作 | 「付与・消化」＝登録画面へ／「詳細」＝個人管理画面へ |

- 上部の検索ボックスで氏名・社員コードを絞り込めます。
- 表示対象は在籍中の社員です（「在籍中／全員／退職者」の切替欄がありますが、現状は表示内容を切り替えません。→ 09）。

---

## 2. 有給を付与する

**場所：有給管理 → 付与・消化登録**

1. 「社員検索」に**社員コード**を入力して「検索」（Enter でも可）。従業員一覧の「付与・消化」ボタンから来た場合は自動検索されます。
2. 社員情報と「有給状況」（付与累計・消化累計・残・消化率）が表示されます。
3. 付与できる状態なら、緑色の「**付与処理**」カードが現れ、
   `勤続 ◯ ヶ月・週 ◯ 日勤務 → ◯ 日付与` と自動計算結果が出ます。
4. **付与日**（初期値は今日）と**付与日数**（ルールの値が入っている。必要なら変更可）を確認する。
5. 「**付与する**」→確認ダイアログで OK。

### 知っておくべきこと
- 付与日数はルール表（勤続月数×週勤務日数）から決まります。**到達済みの最大の区分**が使われます（例：勤続20か月→「1年6か月」の区分）。
- 勤続6か月未満の社員は「ルールが見つかりません」と表示され、付与できません。
- 画面は**「今この社員に付与できる日数の目安」を表示するだけ**です。**付与済みかどうかのチェックはしていません**。同じ区分で何度でも付与ボタンを押せてしまうため、**二重付与に注意**してください（付与ログで確認してから実行）。
- 有効期限は「付与日＋2年−1日」（設定で年数変更可）。例：2026-04-01付与 → 2028-03-31まで。
- 入社日が未登録の社員は付与できません（「入社日が登録されていません」）。

## 3. 有給の消化（取得日）を登録する

**場所：有給管理 → 付与・消化登録 → オレンジ色の「消化登録」カード**
（残日数が1日以上ある社員のみ表示されます）

1. 社員を検索する。
2. **消化日**、**消化日数**、**備考（任意）**を入力する。
3. 「**消化を登録する**」→確認で OK。

### 登録できない場合（エラー）
| 表示メッセージ | 原因 |
|---|---|
| 法定休日（または祝日）には有給休暇を取得できません | 指定日が休日設定の曜日（初期：日曜）または国民の祝日 |
| ◯◯ は既に ◯ 日の消化が登録されています | 同じ社員・同じ日に消化が既にある（1日に1回しか登録不可） |
| 消化単位は ◯ 日のみ有効です | ルール設定の「消化単位」にない日数（初期は1日のみ） |
| 残日数（◯日）が不足しています | 有効な有給の合計が足りない |

### どの有給から減るか
**有効期限が近いものから先に**減ります（先入れ先出し）。1回の消化が複数の付与にまたがることもあり、その場合は自動で分けて記録されます。

## 4. 個人管理画面（1人分を詳しく見る）

**場所：従業員一覧の「詳細」ボタン**（またはメニューには出ない `…page=pl-employee-detail&code=社員コード` の URL）

表示内容（上から）：

1. **社員情報**（入社日・勤続期間・雇用区分・週勤務日数）と「付与・消化登録へ」ボタン
2. **有給サマリー（現在有効期間内）**（左）
   - 付与日数／消化日数／消化率／残日数（いずれも**今有効な付与だけ**の累計）
   - 対象期間：有効な付与のうち最古の付与日〜最新の有効期限
3. **今年の消化状況（付与起算）**（右）
   - 今年の消化数。付与が1件もない場合は「付与記録がないため表示できません」
4. **年5日取得アラート**（条件を満たすと黄色の警告）
   > ⚠️ 年5日の取得義務に対し、今年の消化が ◯ 日です。期限（◯）まで3か月を切っています。計画的な取得をご案内ください。
5. **有給申請**（MAT から届いた希望の一覧と、受理／却下ボタン）→ 第5章
6. **直近の付与**（3件）。4件以上ある場合は「全付与ログを見る」で全件展開
7. **消化ログ**（「消化ログ（◯件）を見る」で展開：日付・日数・備考）

## 5. 有給申請（MAT の希望）を受理・却下する

勤怠アプリ（MAT）で社員が有給の希望日を保存すると、自動的に**「申請中」**として届きます。

**場所：個人管理画面の「有給申請」カード**（従業員一覧の赤バッジからも移動できます）

| 操作 | 結果 |
|---|---|
| ✓ 受理 | 管理者コメント（任意）を入れて確定 → ステータスが「受理済み」になり、**その日に1日の消化が自動登録される**（備考に「有給申請受理（申請ID: ◯）」） |
| ✕ 却下 | 管理者コメント（任意）を入れて確定 → 「却下」になる。消化は登録されない |

### 注意
- 祝日・法定休日の希望は申請自体が作られません。
- 同じ日付の申請が既にあると新規には作られません（ただし**却下済みの日付で再申請すると、同じ申請が「申請中」に戻ります**）。
- **受理時、残日数不足などで消化登録に失敗しても「受理済み」にはなってしまいます**。この場合はメッセージに「付与・消化登録ページから手動で登録してください」と出るので、必ず手動で消化を登録してください。
- 受理済みの申請は後から却下できません（消化ログの削除機能は現状ありません）。
- 申請の一覧専用画面（有給申請管理）は現在メニュー非表示です。

## 6. CSVインポート（過去データの一括登録）

**場所：有給管理 → 有給インポート**（「付与インポート」「消化インポート」の2タブ）

### 共通ルール
- 文字コード **UTF-8**（BOM付き可）、拡張子 `.csv`（`.txt` 可）、30MBまで。
- 1行目は**見出し行として読み飛ばされます**。
- 日付は `YYYY-MM-DD` または `YYYY/M/D`。
- **2段階方式**：①ファイルを選んで「内容を確認（プレビュー）」→ ②結果を見て「この内容で取込む」。プレビューの時点では何も登録されません。プレビュー結果の保持は**1時間**（過ぎたらやり直し）。
- エラー行は取り込まれず、行番号と理由が表示されます（最大200行分表示）。

### 6-1. 付与インポート
- 列順：**社員番号, 有給発生日, 付与日数**
- 失効日は自動計算（付与日＋期間−1日）。失効日が今日より前なら**失効済み（残0）**、そうでなければ**残＝付与日数（満額）**で登録。
- 社員マスタにない社員番号はエラー。「社員番号＋付与日」が既にあれば重複としてスキップ。

### 6-2. 消化インポート（**付与インポートを先に完了**してから）
- 列順：**社員番号, 消化日**（1行＝1日の全休。日数は1.0固定）
- 各消化は**その消化日に有効だった付与**に、付与日の古い順に充当されます。失効済みの付与にも当時の消化として記録されます（残日数は変えない）。
- 充当できる付与がない、または残りが足りない行はエラー。同じ「社員番号＋消化日」が既にあればスキップ。
- **休日（祝日・日曜）かどうかのチェックはインポートでは行いません。**

## 7. 集計表

**場所：有給管理 → 集計表**

1. **集計期間**（開始〜終了）を指定（初期値：今年の1/1〜12/31）。
2. **集計方式**を選ぶ。
   - **付与ベース**：期間内に**付与された**有給を対象に集計
   - **消化ベース**：期間内に**消化があった**有給（の付与）を対象に集計
3. 「集計する」。

出力列：社員コード／氏名（個人管理画面へのリンク）／入社日／有給発生日（その社員の最初の付与日）／付与日数／消化日数／残日数／消化率。
消化率は 50%未満＝赤、80%以上＝緑 で色分けされます。計算の詳細は 03 を参照。

## 8. 有給ルール設定（管理者向け）

**場所：有給管理 → 有給ルール設定**（`manage_custom_plugin_settings` 権限が必要）

| 設定 | 内容 |
|---|---|
| 付与日数ルール | 勤続期間（6か月〜6年6か月以上）×週勤務日数（週1〜週6）の表。各セルに日数入力 |
| ルール適用開始日 | この日付以降のルールとして保存される（過去の付与には影響しない） |
| 付与から何年間繰り越し可能か | 入力欄はあるが**現在の計算には使われていない**（09 参照） |
| 付与から何年間で消滅するか | 有効期限の年数（初期2年）。付与登録・CSV取込の失効日計算に使用 |
| 年間最低取得義務日数 | 入力欄はあるが**現在の計算には使われていない**（アラートは「5日」固定） |
| 消化単位 | 1日単位／半日単位（0.5）。チェックした単位のみ消化登録で選べる |
| 法定休日（曜日） | チェックした曜日は消化・申請ができない（初期：日曜） |
| 国民の祝日を休日として扱う | ON なら祝日も消化・申請不可 |
| 祝日データ | 「内閣府CSVから祝日を取得・更新」ボタン |

最後に必ず「**ルールを保存する**」を押してください。

> ⚠ 週勤務日数の列は「週1〜週6」です。初期データは**週5ではなく「週6」列にフルタイム用の値（10/11/12/14/16/18/20日）**が入ります。週5勤務の社員に付与するには**「週5」列に値を入力して保存**する必要があります（09 の課題①）。

## 9. テストデータ削除（管理者向け・要注意）

**場所：有給管理 → テストデータ削除**（`manage_custom_plugin_settings` 権限）

- **物理削除で元に戻せません。**
- 削除対象：付与ログ・消化ログ・申請ログ。**ルール・設定・祝日は削除されません。**
- 「社員別」：社員コードを入れて「件数確認」→内容確認→削除（確認ダイアログあり）。
- 「全件」：全社員分を一括削除（確認ダイアログあり）。
- **本番運用では、全件削除は実行しないでください。**

## 権限の目安

| やりたいこと | 必要な権限 |
|---|---|
| 一覧・個人管理・集計・検索（閲覧） | `access_custom_plugins` |
| 付与登録・消化登録・申請の受理/却下・CSV本実行 | `edit_custom_plugins` |
| ルール設定・祝日更新・テストデータ削除 | `manage_custom_plugin_settings` |

※ 失効処理は `edit_custom_plugins` 権限のユーザーが画面を開いたときに実行されます。
