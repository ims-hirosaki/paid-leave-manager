# 有給管理システム 仕様書セット（索引）

> この資料群は、WordPress プラグイン「有給管理システム（paid-leave-manager）v1.2.0」のソースコードをリバースエンジニアリングして作成した仕様書です。
> NotebookLM / Gem のソースとして使うことを前提に、**エンジニア**と**利用者（人事・総務担当者）**の両方の質問に答えられる構成にしています。
> 根拠はすべて実装コードです。README と実装が食い違う箇所は「09_既知の課題と実装差異.md」にまとめています。**食い違う場合は実装（本資料）を正としてください。**

## 回答するときの注意（Gem / NotebookLM 向け）

- 利用者向けの質問には **02・03・08・10** を優先して参照し、専門用語（テーブル名・関数名）は避けて回答する。
- エンジニア向けの質問には **04〜07・09** を優先して参照し、必要に応じて 03 の計算規則を引用する。
- 数値・日付の計算は 03 の式と例に従う。
- 資料に書かれていないこと（外部プラグイン `employee-manager` や MAT の内部仕様など）は、推測で答えず「資料の範囲外」と明示する。
- 「09」に載っている不具合・注意点は、該当する質問のときに必ず補足として伝える。

## システムの一言要約

社員の**入社日**と**週勤務日数**から労働基準法に沿った**有給休暇の付与日数**を決め、付与（発生）・消化・失効を**社員ごとに記録・集計**する WordPress 管理画面プラグイン。消化は**有効期限が近い付与から順に**充当される。勤怠アプリ（MAT）から届く有給希望を**受理すると自動で消化登録**される。過去データは **CSV で一括取込**できる。
